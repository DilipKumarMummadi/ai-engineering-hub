# Workflows

This document describes the future workflow architecture. No workflows exist yet.

## Concept

A workflow is a multi-step engineering process that combines multiple capabilities (skills, agents, rules, templates) into a repeatable sequence.

## Intended Examples

- Feature Development
- Bug Fix
- Pull Request
- Production Incident
- Release
- Dependency Upgrade

These are planned examples only and have not been implemented.

## Naming

Use lowercase kebab-case, for example `feature-development` or `dependency-upgrade`.
